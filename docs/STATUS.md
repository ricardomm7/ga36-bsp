# Bring-up status

This is a clean-room downstream BSP, not a repackaged vendor image.

Target: GA36-MB V1.2 (R36S), Allwinner A33. The recovered fex
(`output/sys_config.fex`) is the frozen hardware spec.

Strategy: **keep the stock Allwinner bootloader** (BROM → boot0/boot1 → stock
U-Boot → Android boot image) and replace only the kernel. A full mainline
SPL+U-Boot port was attempted and abandoned (see `docs/spl-vs-boot0-audit.md`
for why). The build produces exactly **one** image,
`output/firmware/ga36-stockboot.img`.

Config base: `sunxi_defconfig` (`board/ga36-mb-v1.2/linux-ga36.config`) with
fex rail values (DCDC1/2/3/5 = 3.3/1.1/1.26/1.35 V). The kernel relies on the
stock boot0 having initialised DRAM. The DTS declares an explicit `/memory`
node (512 MiB) because the stock boot1 does not reliably fix the RAM size up
via ATAGs (`CONFIG_ARM_ATAG_DTB_COMPAT` is kept but no longer relied upon;
the R36S spec claims 1 GiB — if the unit really has 1 GiB, the upper half is
simply unused until the size is confirmed on hardware).

Kernel cmdline is forced (`CONFIG_CMDLINE_FORCE`):
`root=/dev/mmcblk0p1 rootfstype=ext4 rootwait rw init=/sbin/init
earlycon=uart,mmio32,0x01c28800 loglevel=8 panic=10` — the stock bootloader's
own bootargs are ignored.

## Build

**Single entry point** `./build.sh` (bootstrap once with `./bootstrap.sh`).
Pipeline: `build-linux.sh` → `build-initramfs.sh` → `package-stock.sh`.
Artifacts land in `output/firmware/`.

## Verification rule (this session onward)

Static analysis (disassembly, file reads, offset math) proves the **file**
is correct — never that the **hardware** ran it. A fix is a *hypothesis*
until a hardware test changes the observable behaviour. `package-stock.sh`
verifies at build time: boot0 eGON checksum, `ANDROID!` magic @172032, MBR
signature, partition start.

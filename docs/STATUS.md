# Bring-up status

This is a clean-room downstream BSP, not a repackaged vendor image.

Target: GA36-MB V1.2 (R36S), Allwinner A33. The recovered fex
(`output/sys_config.fex`) is the frozen hardware spec.

| Area | State | Evidence / next gate |
|---|---|---|
| Original-media partition map | discovered | `docs/analysis.md` generated by `./analyze.sh` |
| Automated extraction | implemented | `./extract.sh`, read-only input |
| Hardware spec | frozen | `output/sys_config.fex`, `output/hardware-report.md` |
| U-Boot 2025.07 | built | `scripts/fw/build-uboot.sh`, `uboot/` board files, SPL+U-Boot in SD image |
| Linux 6.12.41 | built | `scripts/fw/build-linux.sh`, `dts/sun8i-a33-ga36-mb-v1.2.dts`, saved `board/ga36-mb-v1.2/linux-ga36.config` |
| Initramfs (static BusyBox) | built | `scripts/fw/build-initramfs.sh`, getty on ttyS2 |
| Bootable SD image | built | `scripts/fw/package-sd.sh`, `output/firmware/ga36-mb-v1.2.img` (SPL @ LBA16, U-Boot @ LBA80, ext4 @ LBA2048) |
| Serial console milestone | pending | next: flash image, capture UART2 log |
| OTG / SD2 / FN bindings | intentionally unassigned | must never be guessed from board family similarity |
| Display (JD9366 DSI) | not enabled | no upstream panel driver; see DTS comment + `output/migration-plan.md` |
| Buildroot rootfs | postponed | existing external tree is RK3326/aarch64 scaffold; not yet migrated |

U-Boot + Linux configs come from `sunxi_defconfig`/`A33-OLinuXino` bases with
fex DRAM/rail values (DRAM 552 MHz, ZQ 0xf777, DCDC1/2/3/5 = 3.3/1.1/1.26/1.35 V).

Build pipeline (run in order): `build-uboot.sh` → `build-linux.sh` →
`build-initramfs.sh` → `package-sd.sh`. Artifacts land in `output/firmware/`.

The old partition layout is forensic evidence only; `scripts/fw/package-sd.sh`
owns the new image layout.
